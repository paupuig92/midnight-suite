# Midnight Suite

Eines de vídeo de Midnight Group — by Puig.

**Descarrega l'última versió:** [Midnight-Suite.dmg](https://github.com/paupuig92/midnight-suite/releases/latest/download/Midnight-Suite.dmg)

Requisits: Mac amb Apple Silicon (M1 o posterior) i macOS 14 o posterior.
Un cop instal·lada, l'app s'actualitza sola.

Si el Mac diu que no pot verificar l'app: Configuració del Sistema › Privacitat i seguretat › Obre igualment.
